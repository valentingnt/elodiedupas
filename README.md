# elodiedupas

Site one-page statique d'Élodie Dupas, hébergé sur Vercel.

- `index.html` — la page (HTML + CSS inline, pas de build)
- `assets/` — meme + polices Computer Modern (`assets/fonts`, licence OFL)

Aperçu local : `npx serve .` · Déploiement : `vercel --prod` (ou connecter le repo GitHub à Vercel).
